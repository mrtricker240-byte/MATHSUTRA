CLASS 12 MATHEMATICS · CHAPTER 6

Applications of
Derivatives

Learn how derivatives help us study rates of change, increasing and decreasing functions, tangents, normals and optimisation problems.

Language: English · Mode: Boards

1. Rate of Change

If one quantity depends on another, its rate of change is found by differentiation.

Rate of change of y with respect to x = dy/dx

If y = x², then:

dy/dx = 2x

At x = 3, the instantaneous rate of change is 2(3) = 6.

Always check which quantity is changing and with respect to which variable.

2. Increasing and Decreasing Functions

Derivatives help identify where a function increases or decreases over an interval.

f′(x) > 0 ⇒ f is increasing on the interval
f′(x) < 0 ⇒ f is decreasing on the interval

These tests are applied over an interval where the function is differentiable.

Example: f(x) = x²

f′(x) = 2x

For x < 0, f′(x) < 0, so the function is decreasing on (−∞, 0).

For x > 0, f′(x) > 0, so the function is increasing on (0, ∞).

3. Tangents and Normals

The derivative at a point gives the slope of the tangent to a curve.

Tangent slope at x = a: m = f′(a)

If the curve passes through (a, f(a)), the tangent equation is:

y − f(a) = f′(a)(x − a)

The normal is perpendicular to the tangent. If the tangent slope is non-zero:

Normal slope = −1/f′(a)
y − f(a) = −[1/f′(a)](x − a)

If the tangent is horizontal, the normal is vertical; use x = a.

Example

Find the tangent to y = x² at x = 2.

f(2) = 4, f′(x) = 2x, f′(2) = 4
y − 4 = 4(x − 2) ⇒ y = 4x − 4

4. Approximations

For a small change Δx, the change in y can be approximated using the derivative.

Δy ≈ dy = f′(x)Δx

Therefore:

f(x + Δx) ≈ f(x) + f′(x)Δx

Example

Estimate √(4.1) using the linear approximation near x = 4.

Take f(x) = √x, so f(4) = 2 and f′(x) = 1/(2√x).

f′(4) = 1/4, Δx = 0.1
√4.1 ≈ 2 + (1/4)(0.1) = 2.025

5. Critical Points

Critical points occur at interior points of a function's domain where its derivative is zero or does not exist.

f′(x) = 0

Solving this equation identifies stationary points, but not every stationary point is a maximum or minimum.

First Derivative Test

  • f′ changes from positive to negative: local maximum.
  • f′ changes from negative to positive: local minimum.
  • No sign change: neither a local maximum nor a local minimum by this test.

6. Maxima and Minima

A local maximum is a point where nearby function values are no greater than the value at the point. A local minimum is defined similarly with no smaller nearby values.

Second Derivative Test

Suppose f′(a) = 0:

f″(a) < 0 ⇒ local maximum at x = a
f″(a) > 0 ⇒ local minimum at x = a

If f″(a) = 0, the test is inconclusive; use another method.

Example: f(x) = x² − 6x + 5

f′(x) = 2x − 6 = 0 ⇒ x = 3
f″(x) = 2 > 0 ⇒ local minimum
f(3) = 9 − 18 + 5 = −4

Thus the minimum value is −4 at x = 3.

7. Optimisation Problems

To find a maximum or minimum in a word problem:

  1. Identify the quantity to optimise.
  2. Express it as a function of one variable.
  3. Find its derivative.
  4. Set the derivative equal to zero and solve.
  5. Check whether the result is a maximum or minimum.
  6. Check domain restrictions and any endpoints where relevant.

Example: Maximum Product

Two positive numbers have sum 10. Find the maximum possible product.

Let one number be x; the other is 10 − x.

P(x) = x(10 − x) = 10x − x²
P′(x) = 10 − 2x = 0 ⇒ x = 5
P″(x) = −2 < 0 ⇒ maximum

The numbers are 5 and 5, and the maximum product is 25.

🧠 Solved Examples

Example 1 — Increasing or Decreasing

Find the intervals of increase and decrease for f(x) = x² − 4x.

f′(x) = 2x − 4

Set f′(x) = 0: x = 2.

For x < 2, f′(x) < 0; for x > 2, f′(x) > 0.

Decreasing: (−∞, 2); Increasing: (2, ∞)

Example 2 — Tangent

Find the tangent to y = x³ at x = 1.

f(1) = 1, f′(x) = 3x², f′(1) = 3
y − 1 = 3(x − 1) ⇒ y = 3x − 2

Example 3 — Local Maximum

Find the local maximum of f(x) = −x² + 8x.

f′(x) = −2x + 8 = 0 ⇒ x = 4
f″(x) = −2 < 0 ⇒ maximum
f(4) = −16 + 32 = 16

Example 4 — Rate of Change

If y = 3x² + 2x, find dy/dx at x = 2.

dy/dx = 6x + 2
At x = 2: dy/dx = 12 + 2 = 14

📝 CBSE Board Practice

1. Find the intervals of increase and decrease for f(x) = x² − 8x + 3.

f′(x) = 2x − 8. It is negative for x < 4 and positive for x > 4. Decreasing on (−∞,4); increasing on (4,∞).

2. Find the tangent to y = x² + 1 at x = 1.

Point = (1,2); derivative = 2x, slope = 2. Tangent: y − 2 = 2(x − 1), so y = 2x.

3. Find the local minimum of f(x) = x² − 10x + 7.

f′(x) = 2x − 10 = 0 gives x = 5. Since f″(x) = 2 > 0, there is a minimum. f(5) = −18.

4. Find the normal to y = x² at x = 1.

Point = (1,1); tangent slope = 2, so normal slope = −1/2. Equation: y − 1 = −(1/2)(x − 1).

5. Find the approximate value of (1.02)³ using linear approximation near x = 1.

f(x) = x³, f(1) = 1 and f′(1) = 3. For h = 0.02, f(1.02) ≈ 1 + 3(0.02) = 1.06.
