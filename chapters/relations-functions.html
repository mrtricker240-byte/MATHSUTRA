01 · Foundation Concepts

1. Cartesian Product

If A and B are two non-empty sets, their Cartesian product is
A × B = {(a,b) : a ∈ A and b ∈ B}

Example: A = {1,2}, B = {x,y}

A × B = {(1,x), (1,y), (2,x), (2,y)}
If n(A) = m and n(B) = n, then n(A × B) = mn.

Generally, A × B is not equal to B × A. Ordered pairs (1,x) and (x,1) are different.

2. Relations

A relation R from A to B is any subset of A × B.
R ⊆ A × B
Example: A = {1,2}, B = {3,4}
R = {(1,3), (2,4)}
Here:
  • Domain: first components = {1,2}
  • Range: second components actually used = {3,4}
  • Codomain: target set B = {3,4}
Number of relations from A to B = 2mn
where n(A) = m and n(B) = n.

Why? A × B has mn ordered pairs. Each pair can either be included in a relation or left out.

3. Types of Relations

Reflexive
(a,a) ∈ R for every a ∈ A
Every element must be related to itself. Example: On A = {1,2}, a reflexive relation must include (1,1) and (2,2).
Symmetric
(a,b) ∈ R ⇒ (b,a) ∈ R
If a is related to b, b must be related to a. Example: {(1,2),(2,1)} is symmetric.
Transitive
(a,b) ∈ R and (b,c) ∈ R ⇒ (a,c) ∈ R
Example: If (1,2) and (2,3) are in R, transitivity requires (1,3) to be in R.
Equivalence Relation A relation is an equivalence relation if it is reflexive, symmetric and transitive simultaneously.

4. Functions

A function f from A to B assigns every element of A exactly one image in B.
f : A → B
Remember:
  • Every domain element must have an image.
  • A domain element cannot have two different images.
  • Different domain elements may have the same image.
  • Some elements of the codomain may have no preimage.

5. Types of Functions

One-one / Injective Different inputs always have different outputs.
f(a) = f(b) ⇒ a = b
Example: f(x) = 2x on ℝ.
Many-one Two or more different inputs can have the same output. Example: f(x) = x² on ℝ, since f(2) = f(-2) = 4.
Onto / Surjective Every element of the codomain is reached by at least one domain element.
Range = Codomain
Example: f(x) = x³ from ℝ to ℝ.
Into At least one element of the codomain is not reached.
Range ⊂ Codomain
Example: f(x) = x² from ℝ to ℝ.
Bijective A function that is both one-one and onto.

The classification depends on the specified domain and codomain, not just the formula.

02 · Mapping Diagram

A mapping diagram shows how elements of one set are assigned to elements of another set.

Domain A 1 2 3
Codomain B 2 ← 1 4 ← 2 6 ← 3
f(x) = 2x

The arrows represent 1 → 2, 2 → 4 and 3 → 6. Every domain element has exactly one image.

This mapping is one-one and onto if the codomain is exactly {2,4,6}. If the codomain is {2,4,6,8}, it is into instead.

Vertical Line Test

A graph represents y as a function of x if every vertical line intersects the graph at most once.
One x-value must not have two different y-values.

For example, y = x² passes the vertical line test. A full circle does not, because some vertical lines intersect it at two points.

Important: The vertical line test checks whether a graph defines y as a function of x. It does not, by itself, establish whether a function is one-one or onto.

04 · Formula Vault

n(A × B) = n(A) × n(B)
Number of relations from A to B = 2mn
Number of relations on a set with n elements = 2n²
Number of reflexive relations on a set with n elements = 2n² − n
Number of functions from an m-element set to an n-element set = nm

Here, m and n are non-negative integer set sizes, with the usual counting assumptions. The reflexive-relation formula follows because all n diagonal ordered pairs are compulsory, while the other n² − n pairs are optional.

05 · Solved Examples

Example 1: Number of Relations

If A has 2 elements and B has 3 elements, find the number of relations from A to B.
m = 2, n = 3
Number of relations = 2mn = 22×3 = 2⁶ = 64

Example 2: Number of Functions

A has 3 elements and B has 2 elements. How many functions are possible from A to B?
Each of the 3 domain elements can map to either of the 2 codomain elements.
Number of functions = nm = 2³ = 8

Example 3: Identify the Function Type

Consider f : ℝ → ℝ defined by f(x) = x².
  • Not one-one: f(2) = f(-2) = 4.
  • Not onto ℝ: negative real numbers are not in its range.
  • It is many-one and into for the stated domain and codomain.

Example 4: Equivalence Relation

On integers, define a relation by aRb if a − b is divisible by 3. Is it an equivalence relation?
  • Reflexive: a − a = 0, divisible by 3.
  • Symmetric: if 3 divides a − b, it divides b − a.
  • Transitive: if 3 divides a − b and b − c, it divides a − c.
Therefore, it is an equivalence relation.

06 · Board-Style Practice

Try each question on paper before revealing the answer.

Q1. A set has 3 elements. Find the total number of relations on it.

23² = 2⁹ = 512.
Q2. How many functions can be defined from a 2-element set to a 3-element set?

3² = 9 functions.
Q3. Is f : ℝ → ℝ, f(x) = 2x + 1 one-one? Give a reason.

Yes. If 2a + 1 = 2b + 1, then 2a = 2b, so a = b. Therefore f is one-one.
Q4. Is f : ℝ → ℝ, f(x) = x² onto?

No. Its range is [0,∞), so negative real numbers in the codomain are not reached.
Q5. State the three properties required for a relation to be an equivalence relation.

Reflexive, symmetric and transitive.
