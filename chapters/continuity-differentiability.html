CLASS 12 MATHEMATICS · CHAPTER 5

Continuity and
Differentiability

Understand limits, continuity, differentiability and important derivative rules through clear notes, solved examples and interactive practice.

Language: English · Mode: Boards

1. Limits — Quick Recap

A limit describes the value a function approaches when x approaches a particular number.

lim (x → a) f(x) = L

For a two-sided limit to exist, the left-hand limit and right-hand limit must be equal.

LHL = lim (x → a⁻) f(x)
RHL = lim (x → a⁺) f(x)

Limit exists when: LHL = RHL.

Remember: the limit at a point and the actual function value at that point are not necessarily the same.

2. Continuity at a Point

A function f(x) is continuous at x = a if all three conditions hold:

1. f(a) is defined
2. lim (x → a) f(x) exists
3. lim (x → a) f(x) = f(a)

Example

Check continuity of f(x) = x² at x = 2.

lim (x → 2) x² = 4
f(2) = 2² = 4

Since the limit equals the function value, f is continuous at x = 2.

3. Continuity of Piecewise Functions

For a piecewise function, check the left-hand limit, right-hand limit and value at the joining point.

For continuity at x = a:
LHL = RHL = f(a)

Worked Example

Let f(x) = x + 1 for x < 2, and f(x) = k for x ≥ 2. Find k for continuity at x = 2.

Left-hand limit = 2 + 1 = 3.

Right-hand limit = k, and f(2) = k.

For continuity: 3 = k ⇒ k = 3

4. Differentiability

The derivative represents the instantaneous rate of change of a function. Geometrically, it gives the slope of the tangent to the curve where the derivative exists.

f′(x) = lim (h → 0) [f(x+h) − f(x)] / h

The left-hand derivative and right-hand derivative at x = a must be equal for the derivative to exist there.

LHD = RHD

Important: Differentiability at a point implies continuity there, but continuity does not always imply differentiability.

Classic Example: f(x) = |x| at x = 0

The graph has a sharp corner at zero. Its left-hand derivative is −1 and right-hand derivative is +1. They are unequal, so |x| is not differentiable at zero, although it is continuous there.

6. Product, Quotient and Chain Rules

Product Rule

d(uv)/dx = u′v + uv′

Quotient Rule

d(u/v)/dx = (vu′ − uv′)/v², v ≠ 0

Chain Rule

d[f(g(x))]/dx = f′(g(x)) × g′(x)

Example: y = (3x + 2)⁵

dy/dx = 5(3x + 2)⁴ × 3 = 15(3x + 2)⁴

7. Implicit Differentiation

When x and y occur together in an equation, differentiate both sides with respect to x. Remember that y is a function of x.

Example: x² + y² = 25

2x + 2y(dy/dx) = 0
dy/dx = −x/y, when y ≠ 0

8. Logarithmic Differentiation

Useful when a function contains products, quotients or variable powers.

Example: y = xˣ for x > 0.

ln y = x ln x
(1/y)(dy/dx) = ln x + 1
dy/dx = xˣ(ln x + 1)

9. Parametric Differentiation

If x and y are both expressed in terms of t, then:

dy/dx = (dy/dt) / (dx/dt), provided dx/dt ≠ 0

Example: x = t² and y = t³.

dx/dt = 2t, dy/dt = 3t²
dy/dx = 3t²/(2t) = 3t/2, for t ≠ 0

10. Second-Order Derivatives

The second derivative is the derivative of the first derivative.

d²y/dx² = d/dx(dy/dx)

Example: y = x⁴ − 3x².

dy/dx = 4x³ − 6x
d²y/dx² = 12x² − 6

11. Mean Value Theorems

Rolle's Theorem

If f is continuous on [a,b], differentiable on (a,b), and f(a) = f(b), then there exists at least one c in (a,b) such that:

f′(c) = 0

Lagrange's Mean Value Theorem

If f is continuous on [a,b] and differentiable on (a,b), then some c in (a,b) satisfies:

f′(c) = [f(b) − f(a)] / (b − a)

Learn the hypotheses as well as the conclusion; they matter in theorem-based questions.

12. Quick Concept Check

Q: Is every differentiable function continuous?

Answer: Yes, at any point where it is differentiable.

Q: Is every continuous function differentiable?

Answer: No. For example, f(x) = |x| is continuous but not differentiable at x = 0.

🧠 Solved Examples

Example 1 — Differentiate a polynomial

Find dy/dx if y = 4x³ − 5x² + 7x − 9.

dy/dx = 12x² − 10x + 7

Example 2 — Chain Rule

Differentiate y = sin(2x).

dy/dx = cos(2x) × 2 = 2cos(2x)

Example 3 — Product Rule

Differentiate y = x² sin x.

dy/dx = 2x sin x + x² cos x

Example 4 — Continuity

For f(x) = x² when x ≠ 1 and f(1) = 3, is f continuous at x = 1?

The limit is 1² = 1, but f(1) = 3.

lim (x → 1) f(x) ≠ f(1) ⇒ Not continuous

📝 CBSE Board Practice

Attempt each question first, then reveal the answer.

1. State the three conditions for continuity of f at x = a.

f(a) is defined, the limit as x approaches a exists, and that limit equals f(a).

2. Differentiate y = x⁵ + 3x² − 4.

dy/dx = 5x⁴ + 6x.

3. Differentiate y = eˣ cos x.

Using product rule: dy/dx = eˣ cos x − eˣ sin x = eˣ(cos x − sin x).

4. Find d²y/dx² if y = x³ + 2x.

First derivative = 3x² + 2. Second derivative = 6x.

5. Differentiate y = ln(1 + x²).

dy/dx = 2x/(1 + x²).
