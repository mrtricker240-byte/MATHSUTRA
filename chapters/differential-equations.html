CLASS 12 MATHEMATICS · CHAPTER 9

Differential Equations

Understand order, degree, general and particular solutions, formation of equations and standard solving methods.

Language: English · Mode: Boards

1. What Is a Differential Equation?

A differential equation is an equation involving a dependent variable, an independent variable and one or more derivatives of the dependent variable.

dy/dx = 2x

Its general solution is:

y = x² + C

Because differentiating x² + C gives 2x.

2. Order of a Differential Equation

The order is the highest order derivative present in the equation.

d²y/dx² + 3dy/dx + y = 0

The highest derivative is the second derivative. Therefore, the order is 2.

Another example

d³y/dx³ + (dy/dx)² = x

The order is 3.

3. Degree of a Differential Equation

When the equation is a polynomial in its derivatives, the degree is the power of the highest-order derivative after the equation has been made polynomial in derivatives, without radicals or fractions involving derivatives.

(d²y/dx²)³ + dy/dx = 0

Order = 2, Degree = 3.

(d²y/dx²)² + (dy/dx)⁴ = 0

Order = 2, Degree = 2.

If the equation cannot be expressed as a polynomial in derivatives, its degree is not defined under the usual Class 12 convention.

4. General and Particular Solutions

A general solution usually contains arbitrary constants. A particular solution is obtained when the required conditions determine those constants.

Example

dy/dx = 2x
General solution: y = x² + C

If y = 3 when x = 1:

3 = 1 + C → C = 2
Particular solution: y = x² + 2

5. Formation of Differential Equations

To eliminate arbitrary constants, differentiate the given family of curves as many times as needed, then eliminate the constants.

Example

Form a differential equation from y = Cx², where C is an arbitrary constant.

y = Cx²

Differentiate with respect to x:

dy/dx = 2Cx

From the original equation, C = y/x². Substitute:

dy/dx = 2y/x
x(dy/dx) − 2y = 0

This equation no longer contains C.

6. Variable Separable Method

Use this method when the variables can be separated so that all y-terms appear with dy and all x-terms appear with dx.

dy/dx = f(x)g(y)

Rearrange, then integrate both sides:

dy/g(y) = f(x) dx

Example

Solve dy/dx = xy.

dy/y = x dx
ln|y| = x²/2 + C
y = Ae^(x²/2)

Here A is an arbitrary constant. Also check y = 0 separately, since dividing by y excludes that solution.

7. Homogeneous Differential Equations

A first-order equation of the form dy/dx = F(y/x) can often be solved using the substitution:

y = vx

Then:

dy/dx = v + x(dv/dx)

Substitute into the original equation. The resulting equation may become separable in x and v.

Example setup

dy/dx = 1 + y/x

Put y = vx:

v + x(dv/dx) = 1 + v
x(dv/dx) = 1
v = ln|x| + C
y = x(ln|x| + C), for x ≠ 0

8. First-Order Linear Differential Equations

The standard form is:

dy/dx + Py = Q

Here P and Q may be functions of x. The integrating factor (I.F.) is:

I.F. = e^(∫P dx)

The solution is:

y × I.F. = ∫ Q × I.F. dx + C

Example

Solve dy/dx + y = 1.

P = 1 → I.F. = eˣ
yeˣ = ∫eˣ dx + C
yeˣ = eˣ + C
y = 1 + Ce⁻ˣ

9. Quick Method Selector

  • Variables separate: move x and y terms to opposite sides.
  • dy/dx = F(y/x): try y = vx.
  • dy/dx + Py = Q: use the integrating factor.
  • Arbitrary constants in a family: differentiate and eliminate them.
  • Order and degree questions: identify the highest derivative first.

🧠 Solved Examples

Example 1 — Order and Degree

Determine the order and degree:

(d²y/dx²)⁴ + (dy/dx)³ + y = 0

Highest derivative: second derivative.

Order = 2, Degree = 4

Example 2 — Variable Separable

Solve dy/dx = 3x².

dy = 3x² dx
y = x³ + C

Example 3 — Linear Differential Equation

Solve dy/dx + 2y = 0.

P = 2, Q = 0
I.F. = e^(∫2dx) = e^(2x)
ye^(2x) = C
y = Ce^(−2x)

Example 4 — Particular Solution

Given dy/dx = 2x and y = 5 when x = 2, find y.

y = x² + C
5 = 4 + C → C = 1
y = x² + 1

📝 CBSE Board Practice

1. Find the order and degree of (d²y/dx²)³ + dy/dx = 0.

Order = 2; Degree = 3.

2. Solve dy/dx = 4x³.

y = x⁴ + C.

3. Solve dy/dx = x/y, where y ≠ 0.

y dy = x dx → y²/2 = x²/2 + C → y² = x² + C.

4. Solve dy/dx + y = 0.

I.F. = eˣ. Then yeˣ = C, so y = Ce⁻ˣ.

5. Find the particular solution of dy/dx = 2x if y = 5 at x = 2.

y = x² + C. Using (2,5), C = 1. Hence y = x² + 1.

📌 Final Revision

  • Order means the highest derivative order.
  • Degree is the power of the highest-order derivative when the equation is polynomial in derivatives.
  • For variable separable equations, separate variables before integrating.
  • For homogeneous first-order equations of the form dy/dx = F(y/x), try y = vx.
  • For dy/dx + Py = Q, use I.F. = e^(∫P dx).
  • Use initial conditions to find the arbitrary constant.
