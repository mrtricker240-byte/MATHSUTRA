01 · What is a Matrix?

A matrix is a rectangular arrangement of numbers or elements in rows and columns, enclosed in brackets.

A = [ 1 2 3 ; 4 5 6 ]

This matrix has 2 rows and 3 columns, so its order is 2 × 3.

Order of a Matrix

Order = Number of rows × Number of columns

If a matrix has m rows and n columns, its order is m × n.

Element Notation

A = [aᵢⱼ]

The element aᵢⱼ lies in row i and column j.

03 · Equality of Matrices

Two matrices are equal if they have the same order and all corresponding elements are equal.

If A = B, then aᵢⱼ = bᵢⱼ for every corresponding position.
Example

[[x, 2], [3, y]] = [[5, 2], [3, 7]]

Therefore, x = 5 and y = 7.

04 · Addition, Subtraction & Scalar Multiplication

Addition

A + B = [aᵢⱼ + bᵢⱼ]

Both matrices must have the same order.

Subtraction

A − B = [aᵢⱼ − bᵢⱼ]

Subtract corresponding elements.

Scalar multiplication

kA = [kaᵢⱼ]

Multiply every element by the scalar k.

Properties

A + B = B + A
(A + B) + C = A + (B + C)

05 · Multiplication of Matrices

Matrix multiplication is possible only when the number of columns of the first matrix equals the number of rows of the second matrix.

(m × n)(n × p) = (m × p)

Example

A = [[1, 2], [3, 4]]
B = [[5, 6], [7, 8]]

Multiply each row of A by each column of B, then add the products.

AB = [[19, 22], [43, 50]]
Exam alert: Matrix multiplication is generally not commutative. In general, AB ≠ BA. Also, AB may exist even when BA does not.
A(BC) = (AB)C   ·   A(B + C) = AB + AC

06 · Transpose of a Matrix

The transpose is obtained by interchanging rows and columns.

If A = [[1, 2, 3], [4, 5, 6]], then
Aᵀ = [[1, 4], [2, 5], [3, 6]]

Transpose properties

(Aᵀ)ᵀ = A

(A + B)ᵀ = Aᵀ + Bᵀ

(kA)ᵀ = kAᵀ

(AB)ᵀ = BᵀAᵀ

Symmetric matrix

Aᵀ = A

Skew-symmetric matrix

Aᵀ = −A

07 · Invertible Matrices

A square matrix A is invertible if there exists a matrix A⁻¹ such that:

AA⁻¹ = A⁻¹A = I

For an invertible matrix, the inverse is unique.

For a 2 × 2 matrix:
If A = [[a,b],[c,d]], then
det(A) = ad − bc
When ad − bc ≠ 0:
A⁻¹ = 1/(ad − bc) [[d, −b], [−c, a]]

For matrices with nonzero determinant, the inverse exists. A square matrix with determinant zero has no inverse.

09 · Solved Examples

Example 1 — Find the order

A = [[2, 4, 6], [1, 3, 5]]

There are 2 rows and 3 columns.

Answer: Order = 2 × 3

Example 2 — Find x and y

[[x, 4], [2, y]] = [[7, 4], [2, 9]]

Compare corresponding elements.

x = 7, y = 9

Example 3 — Add matrices

A = [[1, 2], [3, 4]]

B = [[5, 6], [7, 8]]

A + B = [[6, 8], [10, 12]]

Example 4 — Multiply matrices

A = [[1, 2], [3, 4]]

B = [[2, 0], [1, 2]]

AB = [[1×2 + 2×1, 1×0 + 2×2],
[3×2 + 4×1, 3×0 + 4×2]]
AB = [[4, 4], [10, 8]]

Example 5 — Transpose

A = [[1, 2, 3], [4, 5, 6]]

Aᵀ = [[1, 4], [2, 5], [3, 6]]

Example 6 — Inverse of a 2 × 2 matrix

A = [[2, 1], [5, 3]]

det(A) = 2 × 3 − 1 × 5 = 1

A⁻¹ = [[3, −1], [−5, 2]]

10 · Board Practice

Try each question before revealing its solution.

Q1. Find the order of [[1,2],[3,4],[5,6]].

Answer: 3 × 2.

Q2. If A = [[1,2],[3,4]] and B = [[2,3],[4,5]], find A + B.

Answer: [[3,5],[7,9]]. Add corresponding elements.

Q3. Find the transpose of [[2,4,6],[1,3,5]].

Answer: [[2,1],[4,3],[6,5]].

Q4. Is [[1,2],[2,4]] symmetric?

Yes. Its transpose equals the original matrix.

Q5. Find the inverse of [[1,2],[3,7]].

det(A) = 7 − 6 = 1. Therefore A⁻¹ = [[7,−2],[−3,1]].

Q6. For a 2 × 3 matrix A and a 3 × 2 matrix B, what is the order of AB?

Answer: 2 × 2. The inner dimensions match, and the outer dimensions give the result's order.

Q7. State the condition for a square matrix to be invertible.

Answer: Its determinant must be nonzero.

12 · Quick Revision

Remember

  • Addition requires the same order.
  • AB requires columns of A = rows of B.
  • AB is not generally equal to BA.
  • (AB)ᵀ = BᵀAᵀ.
  • A symmetric matrix satisfies Aᵀ = A.
  • A skew-symmetric matrix satisfies Aᵀ = −A.

Common mistakes

  • Confusing rows and columns in the order.
  • Multiplying matrices element-by-element instead of row-by-column.
  • Reversing the order in the transpose of a product.
  • Forgetting to check the determinant before finding an inverse.
