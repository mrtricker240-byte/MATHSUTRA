CLASS 12 MATHEMATICS · CHAPTER 7

Integrals

Master indefinite and definite integration, substitution, integration by parts, partial fractions and important properties with worked examples.

Language: English · Mode: Boards

1. What Is Integration?

Integration is the reverse process of differentiation. If F′(x) = f(x), then:

∫ f(x) dx = F(x) + C

Here, C is the constant of integration. We include it because the derivative of every constant is zero.

Example

∫ 2x dx = x² + C

Check: d(x² + C)/dx = 2x.

3. Linearity of Integration

Integration distributes over addition and subtraction, and constants can be taken outside.

∫ [f(x) ± g(x)] dx = ∫f(x)dx ± ∫g(x)dx
∫ kf(x) dx = k∫f(x) dx

Example

∫ (3x² + 4x − 5) dx = x³ + 2x² − 5x + C

4. Integration by Substitution

Use substitution when the integrand contains a function and its derivative, or a constant multiple of its derivative.

Let u = g(x), then du = g′(x) dx

Example

Evaluate ∫ 2x(x² + 1)⁵ dx.

Let u = x² + 1, du = 2x dx
∫ 2x(x²+1)⁵ dx = ∫u⁵ du
= u⁶/6 + C = (x²+1)⁶/6 + C

5. Integration by Parts

Use this method for products of functions when it simplifies the integral.

∫u v dx = u∫v dx − ∫[u′(∫v dx)]dx

A common mnemonic for choosing u is ILATE: Inverse trigonometric, Logarithmic, Algebraic, Trigonometric, Exponential. It is a guide, not an absolute rule.

Example

Evaluate ∫ x eˣ dx.

Choose u = x, dv = eˣ dx
du = dx, v = eˣ
∫xeˣ dx = xeˣ − ∫eˣ dx
= xeˣ − eˣ + C = eˣ(x−1) + C

6. Integration by Partial Fractions

For a rational function, first make sure the fraction is proper. If necessary, perform polynomial division. Then split it into simpler fractions.

Example

Evaluate ∫ 1/[x(x+1)] dx.

1/[x(x+1)] = 1/x − 1/(x+1)
∫ 1/[x(x+1)] dx = ln|x| − ln|x+1| + C
= ln|x/(x+1)| + C

This result is valid on intervals where the original integrand is defined.

7. Trigonometric Identities in Integration

Identities can simplify trigonometric integrals.

sin²x = (1 − cos 2x)/2
cos²x = (1 + cos 2x)/2
tan²x = sec²x − 1

Example

∫ sin²x dx = ∫(1−cos 2x)/2 dx
= x/2 − sin 2x/4 + C

8. Definite Integrals

A definite integral has lower and upper limits and evaluates to a number.

∫ₐᵇ f(x) dx = F(b) − F(a)

Here F′(x) = f(x), and the integrand must be integrable over the interval.

Example

Evaluate ∫₀² 2x dx.

= [x²]₀² = 2² − 0² = 4

9. Properties of Definite Integrals

∫ₐᵇ f(x)dx = −∫ᵦₐ f(x)dx
∫ₐᵃ f(x)dx = 0
∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫𝒸ᵇ f(x)dx
∫₀ᵃ f(x)dx = ∫₀ᵃ f(a−x)dx

For the last identity, substitute x = a − t and adjust the limits.

Symmetry properties

If f(a−x) = f(x), then ∫₀ᵃ f(x)dx = 2∫₀ᵃ⁄² f(x)dx
If f(a−x) = −f(x), then ∫₀ᵃ f(x)dx = 0

10. Quick Strategy: Which Method?

  • Power or standard form: integrate directly.
  • Function and its derivative together: try substitution.
  • Product of different types: consider integration by parts.
  • Rational function: simplify or use partial fractions.
  • Trigonometric powers: try identities.
  • Definite integral: find an antiderivative, apply limits, or use a valid property.

🧠 Solved Examples

Example 1 — Power Rule

Evaluate ∫(4x³ − 6x + 2) dx.

= x⁴ − 3x² + 2x + C

Example 2 — Substitution

Evaluate ∫ x/(x² + 4) dx.

Let u = x² + 4, du = 2x dx
= ½∫du/u = ½ln(x²+4) + C

Example 3 — By Parts

Evaluate ∫x cos x dx.

u=x, dv=cos x dx; du=dx, v=sin x
= x sin x − ∫sin x dx
= x sin x + cos x + C

Example 4 — Definite Integral

Evaluate ∫₁³ 2x dx.

= [x²]₁³ = 9 − 1 = 8

📝 CBSE Board Practice

1. Evaluate ∫(3x² + 2x + 1) dx.

x³ + x² + x + C.

2. Evaluate ∫ 2x cos(x²) dx.

Let u=x², du=2x dx. Answer: sin(x²) + C.

3. Evaluate ∫ x ln x dx, for x > 0.

By parts: x² ln x/2 − x²/4 + C.

4. Evaluate ∫₀¹ 3x² dx.

[x³]₀¹ = 1.

5. Evaluate ∫ 1/[x(x+2)] dx.

Partial fractions: 1/[x(x+2)] = ½(1/x − 1/(x+2)). Integral = ½ ln|x| − ½ ln|x+2| + C.

  • Check your result by differentiating your antiderivative.
