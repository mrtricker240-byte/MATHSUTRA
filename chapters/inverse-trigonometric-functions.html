01. Introduction

What are inverse trigonometric functions?

Basic Concept

Trigonometric functions convert an angle into a ratio. Inverse trigonometric functions work in the opposite direction: they help us find an angle when the ratio is known.

If sin θ = x, then θ = sin⁻¹(x), subject to the principal value range.

For example, sin(π/6) = 1/2. Therefore, the principal value of sin⁻¹(1/2) is π/6.

Important: The notation sin⁻¹ x means inverse sine, not 1/sin x. The reciprocal is written as cosec x.

Six Inverse Trigonometric Functions

Trigonometric function Inverse function
sin xsin⁻¹ x / arcsin x
cos xcos⁻¹ x / arccos x
tan xtan⁻¹ x / arctan x
cot xcot⁻¹ x / arccot x
sec xsec⁻¹ x / arcsec x
cosec xcosec⁻¹ x / arccsc x

Why Principal Values?

Trigonometric functions are periodic, so one ratio may correspond to many angles. To define an inverse function unambiguously, we restrict the original function to a suitable interval. The resulting inverse value is called the principal value.

Example:
sin θ = 1/2 has multiple solutions, but the principal value is sin⁻¹(1/2) = π/6.

02. Principal Value Branches

Memorise these ranges carefully for CBSE and JEE Main.

Function Principal value range
sin⁻¹ x [−π/2, π/2]
cos⁻¹ x [0, π]
tan⁻¹ x (−π/2, π/2)
cot⁻¹ x (0, π)
sec⁻¹ x [0, π], excluding π/2
cosec⁻¹ x [−π/2, π/2], excluding 0

Quick Memory Tricks

  • sin⁻¹: centred around zero, from −π/2 to π/2.
  • cos⁻¹: from 0 to π.
  • tan⁻¹: like sin⁻¹, but endpoints are excluded.
  • cot⁻¹: from 0 to π, endpoints excluded.
  • sec⁻¹ and cosec⁻¹: their domains require |x| ≥ 1.
Board tip: Learn both the principal value range and the domain. They are different things!

03. Domain and Range

The domain tells us which inputs are allowed; the range tells us which outputs are possible.

Function Domain Range
sin⁻¹ x [−1, 1] [−π/2, π/2]
cos⁻¹ x [−1, 1] [0, π]
tan⁻¹ x ℝ (−π/2, π/2)
cot⁻¹ x ℝ (0, π)
sec⁻¹ x (−∞, −1] ∪ [1, ∞) [0, π], excluding π/2
cosec⁻¹ x (−∞, −1] ∪ [1, ∞) [−π/2, π/2], excluding 0

Domain Examples

Example 1: sin⁻¹(2) is not defined over the real numbers because 2 is outside [−1, 1].
Example 2: tan⁻¹(100) is defined because tan⁻¹ x accepts every real number.
Example 3: sec⁻¹(−2) is defined because |−2| ≥ 1.

04. Important Identities

These identities are especially useful in simplification and board-exam questions.

Fundamental Identities

Identity 1
sin⁻¹ x + cos⁻¹ x = π/2,   x ∈ [−1, 1]
Identity 2
tan⁻¹ x + cot⁻¹ x = π/2,   x ∈ ℝ
Identity 3
tan⁻¹ x + tan⁻¹(1/x) = π/2,   x > 0
Identity 4
tan⁻¹ x + tan⁻¹(1/x) = −π/2,   x < 0
Identity 5
sin⁻¹(−x) = −sin⁻¹ x
Identity 6
tan⁻¹(−x) = −tan⁻¹ x
Identity 7
cos⁻¹(−x) = π − cos⁻¹ x
Identity 8
cot⁻¹(−x) = π − cot⁻¹ x

Double-Angle Identity

tan⁻¹ x + tan⁻¹ y = tan⁻¹((x + y)/(1 − xy))

This form needs care: when xy > 1, the principal value may require adding or subtracting π. Always check the signs and principal value range before using it.

Square-Root Identity

sin⁻¹ x = tan⁻¹(x / √(1 − x²)),   −1 < x < 1
cos⁻¹ x = tan⁻¹(√(1 − x²) / x),   0 < x ≤ 1
Remember: Before using an identity, check its domain and principal value range.

06. Solved Examples

Understand the method, then try similar questions yourself.

Example 1: Evaluate sin⁻¹(1/2)

We know that sin(π/6) = 1/2 and π/6 lies in the principal range [−π/2, π/2].

Answer: π/6

Example 2: Evaluate cos⁻¹(−1/2)

We need an angle in [0, π] whose cosine is −1/2. That angle is 2π/3.

Answer: 2π/3

Example 3: Evaluate tan⁻¹(1)

Since tan(π/4) = 1 and π/4 lies in the principal range of tan⁻¹ x:

Answer: π/4

Example 4: Simplify sin⁻¹(3/5) + cos⁻¹(3/5)

Apply sin⁻¹ x + cos⁻¹ x = π/2.

Answer: π/2

Example 5: Evaluate tan⁻¹(1) + tan⁻¹(0)

tan⁻¹(1) = π/4 and tan⁻¹(0) = 0.

Answer: π/4

Example 6: Evaluate sin⁻¹(−1)

The angle −π/2 lies in the principal range of inverse sine and sin(−π/2) = −1.

Answer: −π/2
