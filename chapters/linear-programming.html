01. Introduction to Linear Programming

Understand optimisation using linear inequalities.

What is Linear Programming?

Linear Programming is a mathematical method used to maximise or minimise a linear objective function while satisfying a set of linear constraints.

General objective function:
Maximise or minimise Z = ax + by

Here, x and y are decision variables, a and b are constants, and Z is the objective function.

Important Terminology

  • Decision variables: The unknown quantities represented by x and y.
  • Objective function: The function to be maximised or minimised.
  • Constraints: Linear inequalities that restrict the possible values of variables.
  • Feasible region: The common region satisfying all constraints.
  • Feasible solution: Any point in the feasible region.
  • Optimal solution: A feasible solution giving the required maximum or minimum value.

Types of Constraints

2x + 3y ≤ 12
x + y ≥ 4
x ≥ 0, y ≥ 0

In most standard production and resource-allocation questions, x and y represent quantities, so non-negativity constraints are included.

Remember: A linear inequality becomes a straight-line boundary when its inequality sign is replaced by an equality sign.

02. Graphical Method

Convert inequalities into boundary lines and identify the common feasible region.

Steps to Solve an LPP

  1. Identify the decision variables x and y.
  2. Write the objective function Z.
  3. Convert the conditions into linear inequalities.
  4. Draw each constraint boundary line.
  5. Identify the half-plane satisfying each inequality.
  6. Find the common feasible region.
  7. Calculate the corner points of the feasible region.
  8. Evaluate Z at every corner point.
  9. Choose the maximum or minimum value as required.

How to Draw a Boundary Line

Consider the line:

2x + y = 6

Put y = 0:

2x = 6 ⇒ x = 3
First point: (3, 0)

Put x = 0:

y = 6
Second point: (0, 6)

Plot both points and join them to obtain the boundary line.

Finding the Correct Half-Plane

For an inequality such as x + y ≤ 5, first draw x + y = 5.

Test the origin (0, 0), provided it is not on the boundary:

0 + 0 ≤ 5 ⇒ True

Therefore, the half-plane containing the origin satisfies this inequality.

If the test point does not satisfy the inequality, choose the opposite half-plane.

03. Corner-Point Method

The key method for solving standard graphical LPP questions.

Fundamental Principle

For a linear programming problem with a non-empty bounded feasible region, an optimal value is attained at at least one corner point of the feasible region.

Therefore, evaluate the objective function at every corner point to determine the maximum or minimum.

Worked Example

Maximise:

Z = 3x + 2y

Subject to:

x + y ≤ 4
x ≤ 2
x ≥ 0, y ≥ 0

The corner points are:

Corner point Z = 3x + 2y
(0, 0) 0
(2, 0) 6
(2, 2) 10
(0, 4) 8
Maximum value: Z = 10 at (2, 2).

Special Cases

  • Unique optimum: Only one corner point gives the optimal value.
  • Multiple optimal solutions: More than one feasible point gives the same optimal value.
  • Unbounded feasible region: The region extends indefinitely. An optimum may or may not exist, depending on the objective function.
  • Infeasible problem: No point satisfies all the constraints simultaneously.

05. Solved Examples

Revise the common patterns asked in examinations.

Example 1: Find the intercepts of 2x + y = 8

Put y = 0: 2x = 8, so x = 4.
Put x = 0: y = 8.

Answer: (4, 0) and (0, 8).

Example 2: Evaluate Z = 4x + 3y at (2, 1)

Z = 4(2) + 3(1) = 8 + 3 = 11.
Answer: Z = 11.

Example 3: Is (1, 2) feasible?

Constraints:

x + y ≤ 4, x ≥ 0, y ≥ 0

Substitute (1, 2): 1 + 2 = 3 ≤ 4. Both coordinates are non-negative, so all the stated constraints are satisfied.

Answer: Yes, (1, 2) is feasible.

Example 4: Find the maximum of Z = x + y

Subject to:

x + y ≤ 6, x ≥ 0, y ≥ 0

The corner points are (0, 0), (6, 0), and (0, 6). The objective function values are 0, 6, and 6.

Answer: Maximum Z = 6. It is attained at every feasible point on the segment x + y = 6 in the first quadrant.

Example 5: Write a non-negativity constraint

If x and y represent quantities that cannot be negative:

Answer: x ≥ 0 and y ≥ 0.

Example 6: Check whether (3, 2) satisfies x + y ≤ 4

Substitute x = 3 and y = 2. We get 3 + 2 = 5. Since 5 ≤ 4 is false, the point does not satisfy this constraint.

Answer: Not feasible for this constraint.

Question 1

Put y = 0: 3x = 12. Answer: (4, 0).

Question 2

Evaluate Z = 2x + 5y at (3, 2).

Z = 2(3) + 5(2) = 16.

Question 3

x ≥ 0 and y ≥ 0.

Question 4

Does (2, 3) satisfy x + y ≤ 6?

Yes. 2 + 3 = 5 ≤ 6.
