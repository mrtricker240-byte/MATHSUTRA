CLASS 12 MATHEMATICS · CHAPTER 8

Applications of Integrals

Learn how definite integrals help calculate areas under curves and areas enclosed between curves.

Language: English · Mode: Boards

1. The Main Idea

Integration can be used to calculate the area between a curve and the x-axis. For a continuous function that is non-negative on [a,b], the area is:

Area = ∫ₐᵇ f(x) dx

If the graph lies below the x-axis, the definite integral is negative there. For geometric area, use the absolute value or split the interval wherever the curve crosses the axis.

Geometric area = ∫ₐᵇ |f(x)| dx

2. Area Under a Curve

Suppose y = f(x) lies above the x-axis between x = a and x = b.

A = ∫ₐᵇ f(x) dx

Example: y = x² from x = 0 to x = 2

A = ∫₀² x² dx = [x³/3]₀²
A = 8/3 square units

Remember: the answer represents area in square units.

3. Area Below the X-axis

When f(x) is negative throughout the interval, its definite integral is negative, but geometric area must be positive.

Geometric area = −∫ₐᵇ f(x) dx, if f(x) ≤ 0 throughout [a,b]

Example: y = −x from x = 0 to x = 2

∫₀² (−x) dx = [−x²/2]₀² = −2
Geometric area = 2 square units

4. Area Between Two Curves

If the upper curve is y = f(x) and the lower curve is y = g(x), then between x = a and x = b:

A = ∫ₐᵇ [f(x) − g(x)] dx

First identify which curve is above the other. If the curves switch order, split the integral at their intersection points.

Example: y = x and y = x² from x = 0 to x = 1

On [0,1], x is above x².

A = ∫₀¹ (x − x²) dx
= [x²/2 − x³/3]₀¹
= 1/2 − 1/3 = 1/6 square units

5. Finding Intersection Points

For curves y = f(x) and y = g(x), solve:

f(x) = g(x)

The solutions provide possible limits for the enclosed region.

Example: y = x² and y = 2x

x² = 2x → x(x − 2) = 0
x = 0 or x = 2

Between 0 and 2, 2x lies above x². Therefore:

A = ∫₀² (2x − x²) dx
= [x² − x³/3]₀² = 4/3 square units

6. Area Using Horizontal Strips

Sometimes it is easier to integrate with respect to y. If the right curve is x = R(y) and the left curve is x = L(y), then:

A = ∫𝚌ᵈ [R(y) − L(y)] dy

Here c and d are the lower and upper y-limits. Use this approach when the curves are easier to express as x in terms of y.

7. Area Between a Curve and the Y-axis

If x = f(y) is to the right of the y-axis and the region extends from y = c to y = d:

A = ∫𝚌ᵈ f(y) dy

For a curve described by y = f(x), you may need to rearrange the equation first.

8. Common Exam Strategy

  • Draw a rough sketch of both curves.
  • Find their intersection points.
  • Determine which curve is above or to the right.
  • Choose dx for vertical strips or dy for horizontal strips.
  • Split the integral if the upper/lower curve changes.
  • Check that the final geometric area is non-negative.

🧠 Solved Examples

Example 1: Area under y = 3x from 0 to 2

A = ∫₀² 3x dx = [3x²/2]₀² = 6 square units

Example 2: Area between y = 2x and y = x²

Intersection points are x = 0 and x = 2. The line is above the parabola on this interval.

A = ∫₀² (2x − x²) dx = 4/3 square units

Example 3: Area between y = x and the x-axis from −1 to 1

The curve crosses the x-axis at x = 0, so split the region.

A = ∫₋₁⁰ (−x) dx + ∫₀¹ x dx
= 1/2 + 1/2 = 1 square unit

Example 4: Area enclosed by y = x² and y = 4

Intersections occur when x² = 4, giving x = −2 and x = 2.

A = ∫₋₂² (4 − x²) dx
= [4x − x³/3]₋₂² = 32/3 square units

📝 CBSE Board Practice

1. Find the area under y = x² from x = 0 to x = 3.

A = ∫₀³ x² dx = [x³/3]₀³ = 9 square units.

2. Find the area between y = x and y = x² from 0 to 1.

A = ∫₀¹ (x − x²)dx = 1/6 square units.

3. Find the intersection points of y = x² and y = 2x.

x² = 2x gives x = 0 and x = 2. The corresponding points are (0,0) and (2,4).

4. Find the geometric area between y = −x and the x-axis from x = 0 to x = 4.

A = ∫₀⁴ x dx = 8 square units.

5. Find the area enclosed by y = 4 and y = x².

Intersections: x = ±2. A = ∫₋₂² (4 − x²)dx = 32/3 square units.

📌 Final Revision

  • Area under a non-negative curve: ∫ₐᵇ f(x)dx.
  • Area between upper and lower curves: ∫ₐᵇ (upper − lower)dx.
  • For horizontal strips, integrate right curve minus left curve with respect to y.
  • Always find intersection points and check if curves switch order.
  • Geometric area cannot be negative.
