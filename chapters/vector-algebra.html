CLASS 12 MATHEMATICS · CHAPTER 10

Vector Algebra

Explore vectors, components, magnitude, direction, scalar product and vector product with examples and practice.

Language: English · Mode: Boards

1. What Is a Vector?

A vector quantity has both magnitude and direction. Examples include displacement, velocity and force.

A scalar has magnitude only, such as mass, time and temperature.

a⃗ = a₁î + a₂ĵ + a₃k̂

Here a₁, a₂ and a₃ are the components along the x, y and z axes.

2. Types of Vectors

  • Zero vector: magnitude is zero.
  • Unit vector: magnitude is one.
  • Equal vectors: same magnitude and direction.
  • Negative vectors: same magnitude but opposite directions.
  • Parallel vectors: their directions are parallel or antiparallel.
  • Position vector: vector from the origin to a point.
  • Collinear vectors: vectors parallel to the same line.
Unit vector along a⃗ = a⃗ / |a⃗|, provided |a⃗| ≠ 0

3. Magnitude of a Vector

If a⃗ = aî + bĵ + ck̂, then its magnitude is:

|a⃗| = √(a² + b² + c²)

Example

For a⃗ = 2î + 3ĵ + 6k̂:

|a⃗| = √(4 + 9 + 36) = 7

Its unit vector is:

â = (2î + 3ĵ + 6k̂)/7

4. Addition and Subtraction

Add or subtract corresponding components.

a⃗ = a₁î + a₂ĵ + a₃k̂
b⃗ = b₁î + b₂ĵ + b₃k̂
a⃗ + b⃗ = (a₁+b₁)î + (a₂+b₂)ĵ + (a₃+b₃)k̂
a⃗ − b⃗ = (a₁−b₁)î + (a₂−b₂)ĵ + (a₃−b₃)k̂

Example

If a⃗ = 2î + 3ĵ and b⃗ = î − ĵ:

a⃗ + b⃗ = 3î + 2ĵ
a⃗ − b⃗ = î + 4ĵ

5. Position Vector

The position vector of point P(x,y,z) is the vector from the origin O to P.

OP⃗ = xî + yĵ + zk̂

For points A and B, the vector from A to B is:

AB⃗ = OB⃗ − OA⃗
AB⃗ = (x₂−x₁)î + (y₂−y₁)ĵ + (z₂−z₁)k̂

Example

A(1,2,3), B(4,0,5).

AB⃗ = 3î − 2ĵ + 2k̂
|AB⃗| = √(9+4+4) = √17

6. Direction Cosines

If a nonzero vector makes angles α, β and γ with the positive x, y and z axes, respectively, then:

l = cos α, m = cos β, n = cos γ
l² + m² + n² = 1

For a⃗ = aî + bĵ + ck̂:

l = a/|a⃗|, m = b/|a⃗|, n = c/|a⃗|

7. Scalar Product (Dot Product)

The dot product of two vectors produces a scalar.

a⃗ · b⃗ = |a⃗||b⃗| cos θ

In component form:

a⃗ · b⃗ = a₁b₁ + a₂b₂ + a₃b₃

For nonzero vectors, perpendicularity means:

a⃗ · b⃗ = 0

Important properties

  • a⃗ · b⃗ = b⃗ · a⃗
  • a⃗ · a⃗ = |a⃗|²
  • î · î = ĵ · ĵ = k̂ · k̂ = 1
  • î · ĵ = ĵ · k̂ = k̂ · î = 0

Example

a⃗ = î + 2ĵ + 3k̂, b⃗ = 2î − ĵ + k̂.

a⃗ · b⃗ = 1(2) + 2(−1) + 3(1) = 3

8. Angle Between Two Vectors

cos θ = (a⃗ · b⃗)/(|a⃗||b⃗|)

Use this formula when both vectors are nonzero.

Example

a⃗ = î and b⃗ = î + ĵ.

a⃗ · b⃗ = 1
|a⃗| = 1, |b⃗| = √2
cos θ = 1/√2 → θ = 45°

9. Vector Product (Cross Product)

The cross product is a vector perpendicular to both input vectors.

|a⃗ × b⃗| = |a⃗||b⃗| sin θ

Its direction follows the right-hand rule.

a⃗ × b⃗ = (a₂b₃−a₃b₂)î − (a₁b₃−a₃b₁)ĵ + (a₁b₂−a₂b₁)k̂

Unit-vector identities

î × ĵ = k̂; ĵ × k̂ = î; k̂ × î = ĵ
ĵ × î = −k̂; k̂ × ĵ = −î; î × k̂ = −ĵ
a⃗ × b⃗ = −(b⃗ × a⃗)

For parallel vectors, a⃗ × b⃗ = 0⃗.

Example

a⃗ = î + ĵ and b⃗ = î − ĵ.

a⃗ × b⃗ = −2k̂

10. Area Using Vectors

The area of a parallelogram formed by vectors a⃗ and b⃗ is:

Area = |a⃗ × b⃗|

The area of a triangle formed by the same two vectors is:

Area = ½|a⃗ × b⃗|

For points A, B and C, use AB⃗ and AC⃗ to calculate the triangle's area.

11. Formula Vault

|a⃗| = √(a₁²+a₂²+a₃²)
â = a⃗/|a⃗|
a⃗ · b⃗ = a₁b₁+a₂b₂+a₃b₃
cos θ = (a⃗ · b⃗)/(|a⃗||b⃗|)
|a⃗ × b⃗| = |a⃗||b⃗| sin θ
Triangle area = ½|AB⃗ × AC⃗|

🧠 Solved Examples

Example 1 — Magnitude and Unit Vector

Find the magnitude and unit vector of a⃗ = 3î + 4ĵ.

|a⃗| = √(9+16) = 5
â = (3î + 4ĵ)/5

Example 2 — Dot Product

a⃗ = 2î + ĵ − k̂, b⃗ = î + 3ĵ + 2k̂.

a⃗ · b⃗ = 2(1) + 1(3) + (−1)(2) = 3

Example 3 — Perpendicular Vectors

Find k if a⃗ = 2î + kĵ and b⃗ = 3î − 2ĵ are perpendicular.

a⃗ · b⃗ = 0
2(3) + k(−2) = 0
6 − 2k = 0 → k = 3

Example 4 — Cross Product

Find (î + 2ĵ) × (3î + ĵ).

= (1×1 − 2×3)k̂
= −5k̂

Example 5 — Triangle Area

Two sides of a triangle from the same vertex are a⃗ = î + ĵ and b⃗ = î − ĵ.

a⃗ × b⃗ = −2k̂
Area = ½|−2k̂| = 1 square unit

📝 CBSE Board Practice

1. Find the magnitude of 2î − 3ĵ + 6k̂.

Magnitude = √(4+9+36) = 7.

2. Find the unit vector along 3î + 4ĵ.

Magnitude = 5. Unit vector = (3/5)î + (4/5)ĵ.

3. Find (î + 2ĵ) · (3î − ĵ).

3 − 2 = 1.

4. Find î × ĵ.

î × ĵ = k̂.

5. Find the area of a triangle whose two sides from the same vertex are î + ĵ and î − ĵ.

Cross product = −2k̂. Area = ½ × 2 = 1 square unit.

📌 Final Revision

  • Magnitude: square root of the sum of squares of components.
  • Unit vector: divide the vector by its nonzero magnitude.
  • Dot product produces a scalar; use it to find angles and test perpendicularity.
  • Cross product produces a vector; use its magnitude to find areas.
  • Cross product changes sign when the order of the vectors is reversed.
  • Direction cosines satisfy l² + m² + n² = 1.
