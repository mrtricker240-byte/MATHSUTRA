01. Basic Concepts

Understand events and conditional probability.

Random Experiment

A random experiment is an experiment whose exact outcome cannot be predicted with certainty before it is performed.

Example:
Tossing a coin or rolling a die.

Sample Space and Events

The sample space is the set of all possible outcomes. An event is a subset of the sample space.

Example: One die roll
S = {1, 2, 3, 4, 5, 6}
A = getting an even number = {2, 4, 6}

Conditional Probability

Conditional probability measures the probability of event A when we know that event B has occurred.

Formula:
P(A | B) = P(A ∩ B) / P(B), provided P(B) > 0

Here, A ∩ B means both A and B occur, and P(A | B) is read as "probability of A given B".

Important: The event after the vertical bar is the given condition. P(A | B) and P(B | A) are generally not equal.

Complement of an Event

P(A') = 1 − P(A)

A' means that event A does not occur.

02. Important Formulas

Revise the key results from the Class XII Probability chapter.

1. Addition Rule

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

If A and B are mutually exclusive, then P(A ∩ B) = 0, so:

P(A ∪ B) = P(A) + P(B)

2. Conditional Probability

P(A | B) = P(A ∩ B) / P(B), P(B) > 0
P(B | A) = P(A ∩ B) / P(A), P(A) > 0

3. Multiplication Theorem

P(A ∩ B) = P(A) P(B | A)
P(A ∩ B) = P(B) P(A | B)

4. Independent Events

Events A and B are independent if the occurrence of one does not change the probability of the other.

P(A ∩ B) = P(A) P(B)

For independent events with positive probabilities:

P(A | B) = P(A)

5. Total Probability Theorem

If B₁, B₂, ..., Bₙ form a partition of the sample space and P(Bᵢ) > 0, then:

P(A) = Σ P(Bᵢ) P(A | Bᵢ)

For two events forming a partition:

P(A) = P(B)P(A | B) + P(B')P(A | B')

6. Bayes' Theorem

P(Bᵢ | A) = [P(Bᵢ) P(A | Bᵢ)] / [Σ P(Bⱼ) P(A | Bⱼ)]

For two possible causes B and B':

P(B | A) = [P(B)P(A | B)] / [P(B)P(A | B) + P(B')P(A | B')]
Exam tip: Total probability calculates the probability of the observed event. Bayes' theorem uses that observation to calculate the probability of a possible cause.

03. Independent and Mutually Exclusive Events

These two concepts are different. Do not confuse them.

Independent Events

Two events are independent when one event occurring does not change the probability of the other.

P(A ∩ B) = P(A)P(B)

Example: Tossing a fair coin twice. The first toss does not affect the result of the second toss.

Mutually Exclusive Events

Two events are mutually exclusive if they cannot happen simultaneously in the same trial.

P(A ∩ B) = 0

Example: On a single die roll, getting a 2 and getting a 5 are mutually exclusive events.

Independent Mutually exclusive
One event does not affect the other. Both events cannot occur together.
P(A ∩ B) = P(A)P(B) P(A ∩ B) = 0
Can have a non-zero intersection. Have no common outcomes.
Key result: Two mutually exclusive events with positive probabilities cannot be independent.

04. Multiplication and Probability Trees

Use conditional probabilities to calculate the probability of successive events.

Example: Two Draws Without Replacement

A bag contains 3 red balls and 2 blue balls. Two balls are drawn one after another without replacement.

Probability that both balls are red:

P(R₁ ∩ R₂) = P(R₁) × P(R₂ | R₁)
= (3/5) × (2/4) = 3/10

After the first red ball is removed, only 2 red balls remain out of 4 total balls.

With Replacement vs Without Replacement

With replacement Without replacement
The item is returned after the draw. The item is not returned.
Probabilities may remain unchanged. Probabilities generally change.
Draws from a well-mixed bag are independent. Draws are generally dependent.

05. Total Probability and Bayes' Theorem

Learn how to solve questions involving multiple sources or causes.

Worked Example

Factory A produces 60% of a company's items, and Factory B produces 40%. The defect rates are 2% for A and 5% for B. Find the probability that a randomly selected item is defective.

Let D represent the event that an item is defective.

P(A) = 0.6,   P(B) = 0.4
P(D | A) = 0.02,   P(D | B) = 0.05

By the total probability theorem:

P(D) = P(A)P(D | A) + P(B)P(D | B)
= (0.6)(0.02) + (0.4)(0.05)
= 0.012 + 0.020
= 0.032

Answer: The probability of selecting a defective item is 0.032, or 3.2%.

Now Find the Probability the Defective Item Came from B

We need P(B | D).

P(B | D) = P(B)P(D | B) / P(D)
= (0.4 × 0.05) / 0.032
= 0.020 / 0.032
= 0.625

Answer: The probability is 0.625, or 62.5%.

Notice the difference: P(D | B) is the defect rate in B, whereas P(B | D) is the probability that a defective item came from B.

07. Solved Examples

Practise common board-exam question types.

Example 1: Find a Conditional Probability

Given P(A ∩ B) = 0.2 and P(B) = 0.5, find P(A | B).

P(A | B) = P(A ∩ B) / P(B) = 0.2 / 0.5.
Answer: 0.4

Example 2: Find an Intersection Probability

If A and B are independent, P(A) = 0.3 and P(B) = 0.4. Find P(A ∩ B).

P(A ∩ B) = P(A)P(B) = 0.3 × 0.4.
Answer: 0.12

Example 3: Complement

If P(A) = 0.7, find P(A').

P(A') = 1 − P(A) = 1 − 0.7.
Answer: 0.3

Example 4: Total Probability

Suppose P(B) = 0.6, P(A | B) = 0.2 and P(A | B') = 0.5. Find P(A).

P(B') = 1 − 0.6 = 0.4.
P(A) = (0.6)(0.2) + (0.4)(0.5)
= 0.12 + 0.20
= 0.32
Answer: 0.32

Example 5: Bayes' Theorem

Suppose P(B) = 0.4, P(A | B) = 0.5 and P(A) = 0.3. Find P(B | A).

P(B | A) = P(B)P(A | B) / P(A).
= (0.4 × 0.5) / 0.3
= 0.2 / 0.3
= 2/3
Answer: 2/3

Example 6: Check Independence

Suppose P(A) = 0.5, P(B) = 0.4 and P(A ∩ B) = 0.2. Are A and B independent?

P(A)P(B) = 0.5 × 0.4 = 0.2. Since P(A ∩ B) = P(A)P(B), the events are independent.
Answer: Yes, A and B are independent.

State the formula for P(A | B).

If P(A) = 0.65, find P(A').

Question 4

What condition defines mutually exclusive events?

P(A ∩ B) = 0.

Question 5

What is the purpose of Bayes' theorem?

It calculates the conditional probability of a possible cause after observing an event.

P(A ∩ B) = P(A)P(B | A) = 0.4 × 0.5 = 0.2.
